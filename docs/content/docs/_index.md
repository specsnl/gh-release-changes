Welcome to the `gh release-changes` documentation. `gh release-changes` is a [gh](https://cli.github.com)
extension that reads GitHub's generated release notes and renders the changes for different audiences.

Start with [Usage]({{< ref "usage" >}}) to drive the tool, and [the release flow]({{< ref "usage/release-flow.md" >}})
for where it fits in a release. [Guides]({{< ref "guides" >}}) put it to work in CI and with an agent, and
[Architecture]({{< ref "architecture" >}}) explains how and why it works the way it does.
