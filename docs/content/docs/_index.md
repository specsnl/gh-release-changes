Welcome to the `gh release-changes` documentation. `gh release-changes` is a [gh](https://cli.github.com)
extension that reads GitHub's generated release notes and renders the changes for different audiences.

Start with [Usage]({{< ref "usage" >}}) to drive the tool, and [Architecture]({{< ref "architecture" >}}) for how
and why it works the way it does.
